CHARACTER SETS - ARTWORK FILE NAMES
==================================================================

Artwork is matched by FILE NAME. Drop a file into this folder using
one of the names below and it replaces the drawn placeholder.
No code changes and no clicking upload one item at a time.

Accepted extensions:  .jpg  .jpeg  .png  .webp

Character sets have several poses: add -1, -2, -3 and so on to the code.
For example, char-01 with 8 poses becomes:
   char-01-1.jpg  char-01-2.jpg  ...  char-01-8.jpg
A single shared image named char-01.jpg also works.

Recommended size: 600 x 600 px (square, white background)
